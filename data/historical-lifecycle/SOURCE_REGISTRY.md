## Entry rules

- Record exact action date only when source states it or supports transparent exact-date derivation.
- Keep founding-anchor date, precision, evidence text and source URL together.
- Use historical primary source mode only with source-linked lifecycle episode and approved action.
- Year/month-only sources remain useful research leads but cannot produce age-matched exact-day comparisons.
